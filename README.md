# OPENING THE APP
# Use VSCode or something, It should open fine as a .py!
# If not, you may open the file manually.

# When opening the app, the following Labels should be visible at the top.
# Title
# Artist
# Comment 

# Top Buttons 
# Press the "A" Button to add a song.
# The "S" Button will attempt to save the App's current state, but this is still wip.
# The "L" Button will attempt to load a JSON that the App saved previously. 
# The "C" Button, which clears all the songs in the list.
# The "U" Button will attempt to undo a change but this isn't working.
# The "R" Button will attempt to redo a change, but this isn't working.

# Buttons below Top Buttons
# The "-" Button will minimize the top frame with the top buttons and labels, which we will refer to as the sideFrame (although it's not at the side.)
# Once minimizing and hiding the sideframe, it changes into a "+". This will then reopen the sideframe tab.
# The "S" Button will showcase the Settings tab. For now, it's just customability color settings for the widget colors.

# Songs
# When a Song is added, it should appear in the middle of application with {songname} by {artist}. There will be 3 buttons for each song.
# The "i" Button will showcase the comment that the song has attached to it.
# The "x" button will remove this specific song.
# The "*" button will open the specific song's configuration options.
# The configuration options are selectable through numbers, 1-4.
# 1. Name
# 2. Artist
# 3. Comment
# 4. Color (This will then open up a color picker.)
